# Quick Commerce Operations Analytics Dashboard

## Project Overview
This project analyzes quick-commerce operational performance using Excel, Python, SQL, and Power BI.

The dashboard focuses on:
- Revenue and order performance analysis
- Delivery efficiency and delay monitoring
- Customer behavior insights
- Product category performance
- Strategic operational recommendations

## Tools Used
- Python
- SQL (MySQL)
- Power BI

## Project Workflow
1. Data cleaning and preprocessing using Python
2. SQL database creation and KPI analysis
3. Interactive Power BI dashboard development
4. Business insights and operational recommendations

## Dashboard Pages
1. Executive Overview Dashboard
2. Delivery Performance Analytics Dashboard
3. Customer & Product Insights Dashboard

## Key Insights
- Top-performing companies contribute the highest revenue share
- Delivery delays increase significantly with longer distances
- Discounts positively impact order values and customer activity
- Medium-value customers form the largest customer segment

## Business Recommendations
- Optimize delivery routes in slow-performing cities
- Improve rider allocation efficiency
- Expand top-performing product categories
- Improve customer experience to boost ratings
